# Field Specimen UI rule

Before editing a matching interface file:

1. Read `FIELD_SPECIMEN_STYLE_GUIDE.md` completely.
2. Follow the aesthetic continuity contract and workflow in `AGENTS.md`.
3. Reuse existing tokens and component patterns before introducing variants.
4. Use the smallest appropriate retrofit level for existing builds.
5. Preserve the signature system: bone paper, near-black ink, acid-yellow activity, square ruled modules, grotesk display type, monospaced telemetry, one dominant working surface, and truthful instrumentation.
6. Include the Field Specimen continuity note required by `AGENTS.md` in the final handoff.

If the user's explicit direction conflicts with this rule, follow the user and report the intentional deviation.
